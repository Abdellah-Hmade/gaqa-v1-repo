# GAQA — Real Project

This is the real GAQA project as is. Secrets have been removed.

It is provided for reference only and is not intended for use.

For usage, check out the tagged version:

```bash
git checkout v1.0.1-alpha
```

No credentials, tokens, or keys are included. Create your own `.env` from
`.env.example`; `.env` is ignored by git.
